# HELIA — projeto conceitual Alureal

Site e experiência digital demonstrativa para uma clínica integrada fictícia.

## Objetivo
Demonstrar como a Alureal pode organizar uma jornada de saúde digital clara: especialidades, profissionais, agendamento e portal do paciente.

## Recursos
- navegação responsiva;
- seleção de especialidade e profissional;
- agendamento demonstrativo;
- portal do paciente conceitual;
- acessibilidade e redução de movimento;
- zero backend e zero dependências de runtime;
- compatível com GitHub Pages.

> Projeto conceitual. Profissionais, dados e serviços exibidos são fictícios.
